# Layer Lab - Fragrance Layering Companion

A web application that helps you discover perfect fragrance combinations. Extract notes from your favorite perfumes and get personalized layering recommendations.

## Features

- **Fragrance Search**: Search by name, brand, or notes from a curated database of popular fragrances
- **Notes Pyramid**: Visual breakdown of top, heart, and base notes
- **Smart Recommendations**: Algorithm-driven layering suggestions based on note compatibility
- **Layering Tips**: Expert advice on how to apply and combine fragrances

## How It Works

1. **Select a Fragrance**: Search for your favorite perfume or cologne
2. **View Notes**: See the complete breakdown of top, heart, and base notes
3. **Get Recommendations**: Discover fragrances that complement your selection
4. **Learn to Layer**: Get tips on how to apply for the best results

## Tech Stack

- **Next.js 16** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to start exploring fragrances.

## Recommendation Algorithm

The app uses a multi-factor scoring system to recommend layering combinations:

- **Shared Notes**: Fragrances with common notes enhance each other
- **Complementary Categories**: Woody + Citrus, Floral + Musk, etc.
- **Base Note Compatibility**: Most important for long-lasting layering
- **Season & Occasion Matching**: Practical compatibility for real-world use
- **Accord Harmony**: Similar scent profiles work well together
